Selected Work

01

agentlog

LLM Observability

Python · OpenTelemetry · ClickHouse · Helm  ·  pip install agentlog-ai · Repository

OpenTelemetry-native observability for multi-agent LLM systems. It auto-instruments OpenAI and LiteLLM by patching them at the client boundary, so a running system starts emitting traces without a line of application code changing. Analytics sit on ClickHouse with behavioral search and multi-trace comparison, and it ships as a production Helm chart with an autoscaling collector and OAuth2 authentication.

Redaction is opt-in, not on by default. Silently rewriting someone's prompt data seemed worse than making them ask for it.

02

go-kv

Systems Programming

Go · RESP protocol · write-ahead log  ·  Repository

A networked in-memory key-value store written from scratch in Go. It speaks the Redis RESP protocol, so redis-cli works against it out of the box. Write-ahead log with fsync on every write, RWMutex concurrency, dual TTL expiry, and no external dependencies.

11.8MGET ops/sec 85ns/op 1alloc/op

Apple M4 Pro. Store-level benchmarks: in-memory operations only, with no network in the path.

fsync on every write costs 1–5ms. Batching it would be roughly ten times faster and would lose a window of data on crash. I took durability.

03

prediction-market-analytics

Data Engineering

Python · FastAPI · httpx · asyncio · pytest  ·  Repository

A multi-venue prediction market analytics engine. It pulls live quotes from Kalshi and Polymarket, normalises two incompatible formats into a shared quote type, and measures where the venues disagree about the same contract. Read-only by design: no trading, no auth, no database. Around 3,000 lines of Python and 61 tests.

It will not auto-match contracts by keyword. That produces confident, silent, wrong signals, so every pair is verified by hand against both resolution texts.
